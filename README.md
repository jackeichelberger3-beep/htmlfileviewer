# HTML Studio

A dark Google-inspired HTML/CSS/JS editor with:
- multi-tab editing
- preview pane
- settings and themes
- library snippets
- ZIP import support
- plugin architecture
- terminal access key flow
- drag/drop file opening
- search/replace and formatting tools

Open index.html in a browser or upload this folder to GitHub.

Notes:
- keys.js contains the access keys for the secure terminal flow.
- The app is standalone and does not require a build step.
- If you want me to push this to a specific GitHub repo, send the repo URL or owner/name.
